# Glance — landing page concept

Unofficial, bilingual (ES/EN) landing page concept for [Glance](https://github.com/glanceapp/glance), the open-source self-hosted dashboard. Made as a design exercise; not affiliated with or endorsed by the Glance project.

Screenshots and logo in `img/` come unmodified from the [Glance repository](https://github.com/glanceapp/glance/tree/main/docs) (AGPL-3.0).
